# האולפן — מכשירי AI

אב־טיפוס פעיל של הקונסולה: Next.js + React, React Flow לשרשרת האותות,
ו־Supabase כשכבת המידע (אופציונלי בשלב הזה). מנוע ה־AI רץ בצד השרת מול
Claude, כמודול בתוך מערכת חוקים — לא כמנהל של המוצר.

## הרצה

```bash
cp .env.example .env.local   # והכנס מפתח ANTHROPIC_API_KEY
npm install
npm run dev
```

הממשק ב־http://localhost:3000. בלי מפתח API הקונסולה נטענת ועובדת, אבל
כפתור ההרצה יחזיר הודעה שהמנוע לא מחובר.

## המכשיר הראשון

`MIX NOTES` — הופך הערות חופשיות של לקוח לרשימת תיקוני מיקס. הקלט הוא
טקסט אנושי מבולגן; הפלט הוא רשימת פעולות שכל אחת מהן מעוגנת בציטוט מהמקור,
פלוס רשימת שאלות פתוחות שאפשר לשלוח ללקוח כמו שהן.

הפקדים אינם קישוט: כל פקד מתורגם להוראה מפורשת בפרומפט, ולשונית
"ההוראה שנשלחת" מציגה את הטקסט המדויק שנשלח למנוע.

## אוטונומיה

שלוש רמות: הצעה בלבד, טיוטה לאישור, ביצוע אחרי אישור. בשום רמה המכשיר
אינו שולח דבר ואינו מבצע פעולה חיצונית — שלב האישור האנושי מסומן במפורש
בשרשרת האותות.

## Supabase

ללא משתני הסביבה של Supabase, פריסטים והיסטוריה נשמרים ב־localStorage.
עם חיבור, אותו קוד עובד מול הטבלאות שב־`supabase/schema.sql`, כשהרשאות
ברמת השורה מגבילות כל משתמש למידע שלו.

## הצעדים הבאים

1. חיבור משתמשים (Supabase Auth) והעברת שינויי המכשיר לענן.
2. מכשיר שני, כדי לבדוק שהמבנה מחזיק יותר ממקרה אחד.
3. חיבור לאימייל, יומן וקבצים.
4. עורך חיבורים מלא — רק אחרי שהשימוש הוכיח את עצמו.
5. עטיפה ב־Tauri לגרסת מחשב.
